## 6. 专有名词：调参解决不了，靠流程补

**固有短板**，常见错法：英文缩写听成音近汉字、产品名听成常见词、人名听成同音词、行业术语听成字面词。例如 `Harness→Hannis`、`Agent Loop→EdgeLoop`、`LangChain→LongChang`、`RAG→ROG`、`意图识别→一图识别`、`召回率→招回率`。

补救手段，**按可靠性排序**：

1. **看字幕 / 原始文稿**：那是真值，别猜。
2. **换真正异源的引擎拿第二份结果**：同源两版不算。
3. **上下文推断**：结合前后句判断该是哪个词。
4. **建术语对照表**：把音译和实际词记下来，精编稿统一替换，原始稿保留。
5. **原生热词**：部分引擎支持解码期热词或文本偏置，比提示语软引导可靠；但词表要克制，热词会把普通词误写成专名。注意区分「开源权重」与「闭源 API」的能力，别把 API 的特性算到开源模型头上。

> 血泪教训：曾凭「两次转写都落在同一个音上」推断对了一个词，又用同样方法推断错了一个词——**同音只能提高置信度，不能替代真值**。同源模型连这点置信度都要再打折。「两版一致就采信」必须改成「一致只降低风险」。
